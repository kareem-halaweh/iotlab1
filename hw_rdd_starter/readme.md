# ESP32 Temperature & Humidity Monitor

Monitors temperature and humidity using an ESP32 and DHT22 sensor. Sends data to ThingSpeak and turns on an LED when temperature exceeds 30°C.

- **ThingSpeak:** https://thingspeak.mathworks.com/channels/3551632
- **Wokwi:** https://wokwi.com/projects/new/esp32
- **Circuit:** ESP32 + DHT22 + LED
